STUDENT MANAGEMENT SYSTEM
=========================

Technologies:
HTML, CSS, JavaScript, PHP, MySQL

HOW TO RUN (XAMPP):
1. Copy this Student-Management-System folder into C:/xampp/htdocs/
2. Start Apache and MySQL from XAMPP.
3. Open phpMyAdmin: http://localhost/phpmyadmin
4. Import database/database.sql
5. Open: http://localhost/Student-Management-System/

Database settings are in db.php.
Default XAMPP MySQL settings:
host=localhost
user=root
password=empty
database=student_management
